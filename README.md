# 예술in ARCADE — 최종 오디션

[게임 플레이](https://yesulin-arcade.vercel.app/) · [공개 소스](https://github.com/simhokyung/yesulin-audition-arcade) · [Vercel 배포](https://vercel.com/hokyung/yesulin-arcade)

**이 크루들, 다 잡을 수 있어?** 서류 심사부터 최종 오디션까지. 다섯 심사관을 넘어, 당신의 무대를 완성하세요. 배우는 배역으로 가능성을 표현하고, 감독은 배우·조명·음향을 지휘하는 2D 보스 액션 게임입니다. 닉네임만 입력하고 역할을 선택하면 시작할 수 있습니다. 시간제한 없이 진행하며 한 판의 역할은 고정됩니다.

## 플레이

- **시작하기:** 서류 심사부터 최종 오디션까지 연속 도전합니다.
- **연습모드:** 선택한 보스 한 명과 본 도전과 같은 조건으로 대결합니다. 순위에는 등록하지 않습니다.
- **게임 종료:** 전투를 멈추고 확인한 뒤 홈으로 돌아갑니다. 중도 종료한 판은 순위에 등록하지 않습니다.
- **전체 크루 순위:** 모든 기기에서 같은 서버 기록을 확인합니다. 현재 순위는 해당 닉네임의 최고 기록 기준입니다.

| 조작 | 동작 |
|---|---|
| 방향키 | 이동 |
| Q | 누르고 있으면 3연타 반복, 네 번째 묶음은 강마무리 |
| W | 공격 스킬 · 재사용 4.8초 |
| E | 5초 강화 · 재사용 12초 |
| R | 충전 100%와 재사용 42초가 준비되면 컷신 뒤 12연타 |
| Space | 이동 방향으로 회피, 공격 연타 취소 |
| Esc / P | 일시정지·재개 |

다른 창으로 전환하면 자동으로 일시정지합니다. 터치 조작도 제공합니다. 닉네임 입력 예시 ‘맥스’는 안내이며 자동 등록하지 않습니다.

## 배우와 감독

- **배우:** 검사 Q 강마무리로 궁수 W를 강화합니다. E 중 정확한 JUST 회피는 다음 Q를 강마무리부터 시작하게 합니다. R은 검사·궁수·액션 배우로 전환하는 12연타입니다.
- **감독:** 슬레이트 Q로 액션 표식을 쌓고 W로 연쇄 폭발시킵니다. E는 스태프의 조명·음향 후속타와 일반 피격 한 번 보호를 제공합니다. R은 스태프 총동원과 거대 슬레이트 마무리입니다.

## 다섯 심사관

| 관문 | 심사관 | 특징 기술과 회피 |
|---|---|---|
| 서류 심사 | **피노** · 조명감독 | “빨뚜는 못 참지!” 초록 병과 빨간 뚜껑을 **통째로** 던집니다. 시간차 3발의 고정 발사선 옆으로 피하세요. |
| 1차 오디션 | **대길** · 가면연출가 | “추노 시작!” 두 번 추적하고 실제 돌진합니다. 방향 고정 후 옆으로 꺾으면 반격 기회가 열립니다. |
| 2차 오디션 | **이프** · 경계심사관 | “자리해야지~” 위치를 읽어 7곳을 차례로 추적·봉쇄하고 프레임을 시간차로 발사합니다. 예고를 벗어나고 봉쇄된 자리로 바로 돌아가지 마세요. |
| 3차 오디션 | **맥스** · 기록심사관 | “추억이 중요하다~ 남는 건 추억이다~” 연속 촬영, 사진 7연사, 사진틀 통과, 6장 왕복 사진을 사용합니다. 고정된 촬영선 옆으로 피하고 돌아오는 사진도 확인하세요. |
| 최종 오디션 | **무빙** · 종막집행관 | “무빙 좀 보여줘!” 접근 축을 바꾸는 7연속 돌진과 후속 참격을 사용합니다. 돌진 뒤에도 지나간 길을 바로 밟지 마세요. |

피노·대길·이프·맥스는 기존 일곱 기술과 전투 수치를 유지합니다. v22의 최종 보스 무빙은 기존 일곱 기술에 **교차편집·리테이크·킬링무브**를 더한 열 가지 기술을 사용합니다. 가로·세로 칼날벽 사이를 바꿔 타고, 지나온 발자국의 연쇄 폭발을 피하며, 돌진과 측면 칼날을 함께 읽어야 합니다. 공격은 빨간 추적 → 흰색 방향 고정 → 실제 발사 순서로 표시합니다. 무대 장악의 통로와 칼날 틈도 좁아집니다. 조준이 고정되면 발사 전 다시 추적하지 않습니다. 피노와 대길의 전투 수치는 v18과 같습니다. 플레이어 체력 260, 관문 통과 회복 65, QWER 수치도 유지합니다. 본 도전 보스 체력은 피노 2,255 / 대길 3,190 / 이프 4,840 / 맥스 5,200 / 무빙 7,315입니다.

무빙은 교차 칼날벽5개, 기록 지점7곳과 재조준6발, 실제 돌진5회와 측면 칼날10발을 섞습니다. **무빙에게 R을 사용해도 예약된 공격은 컷신 뒤 이어집니다.** 컷신 중 공격 시간은 멈춥니다. 감독의 정밀 W는 현재 예고 한 번을 끊고 후속 공격은 남기며, 무대 장악 예고는0.5초 늦춥니다. 이미 피한 자리로 돌아가거나 한 방향으로 계속 도는 대신 새 고정선을 읽고 방향을 바꿔야 합니다.

원본 사진을 홈·연습·등장·무대 장악 컷신에 사용합니다. 전투는 원본 얼굴 픽셀을 보존하면서 사진의 옷차림을 반영한 2D 몸을 움직입니다. 맥스의 갈색 재킷·휴대폰·크림색 바지도 반영했습니다. 큰 특징 기술 이름과 보스 가까이 뜨는 말풍선으로 크루의 특징을 보여주며, 회피 표식을 가리지 않도록 배치합니다.

## 무대 장악

큰 행동 안내, 목적지 화살표, **민트 ‘여기’ / 금색 ‘다음’**, 의미가 붙은 남은 시간으로 회피합니다. 금색 예고는 지금 들어갈 안전 위치가 아닐 수 있습니다.

- **피노:** 움직이는 민트 조명 안을 따라갑니다. 왕복이면 함께 방향을 바꿉니다.
- **대길:** 번호·모양이 같은 민트 발판으로 갑니다. 이동 신호에는 민트 연결 통로를 따라 다음 발판으로 이동합니다.
- **이프:** 켜진 빔을 피해 민트 통로에 머무릅니다. 빔이 꺼지고 “지금 이동!”이 뜨면 새 통로로 이동합니다.
- **맥스:** 열린 민트 필름 칸을 따라가고, 되감기에는 이전 칸으로 돌아갑니다. 마지막 촬영은 방향이 고정되면 부채꼴 밖으로 피합니다.
- **무빙:** 세 가지 장악을 순환합니다. **라스트 컷**은 다가오는 벽의 민트색 틈으로 이동한 뒤 틈 안에서 조준선을 옆으로 피합니다. **칼날 파도**는 민트색 빈틈에 맞춥니다. **추격 난무**는 가로 7연사 → 세로 7연사 → 3방향 마무리이며 반전 신호에 이동 방향을 바꿉니다. 첫 장악부터 라스트 컷이 등장합니다.

무대 장악의 실제 칼날이나 위험 범위에 닿으면 **최대 체력의 40%**가 감소합니다(현재 최대 체력 260 기준 104). 피격 후 **1초간 장악 재피격을 막아** 탈출할 틈을 줍니다. 계속 위험 범위에 남으면 다시 피해를 받습니다. Space·E·R의 일반 무적·보호 효과로 장악 피해를 무시할 수 없습니다. 생존 피격에는 전투가 계속되고 체력이 소진될 때만 종료합니다. 장악을 끝까지 피하면 **1.8초 반격 기회(무빙은1.1초)**, 보스에게 주는 피해 **20% 증가**가 적용됩니다. 단순 예고 취소는 반격을 주지 않습니다.

최종 관문을 통과한 배우에게는 **최종 오디션 합격!**, 감독에게는 **마지막 장면, 완성!**을 표시하며 예술in 오디션 탐색 또는 배우 모집·심사로 연결합니다.

## 오리지널 전투 BGM

전투 시작 클릭으로 음악을 켭니다. 멜로디·베이스·드럼·코드가 있는 8마디 오리지널 곡을 Web Audio로 연주하며 일반전 136 BPM, 무빙 156 BPM, 무빙 체력 42% 이하 172 BPM으로 긴장감을 높입니다. 편곡은 마디 경계에서 바뀝니다. 무대 장악 중에는 보스별 장악 음악이 전면에 나오고 일반 BGM은 물러납니다. 일시정지·게임 종료·음소거 시 음원을 정리하며, 이전 음소거 선택은 유지합니다. 공격 예고와 피격 효과음이 음악에 묻히지 않도록 별도 버스에서 음량을 조절합니다.

## 공용 순위

**통과 관문 수 → 마지막 관문 통과 시간(짧을수록) → 점수 → 최대 콤보 → 먼저 기록한 시각** 순입니다. 첫 보스를 아직 통과하지 못한 기록은 시간 비교 없이 점수로 비교합니다. 통과 시간은 보스를 잡는 순간 확정한 누적 게임 시간이며 이후 탈락할 때까지 버틴 시간은 반영하지 않습니다. 컷신·히트스톱·관문 전환은 포함하고 일시정지는 제외합니다. 시간 제한은 없습니다. 같은 닉네임의 최고 기록 하나를 표시합니다. 점수는 실제 감소한 적 체력과 JUST 보너스를 사용하며 초과 피해나 플레이 시간에는 보너스를 주지 않습니다.

v18.1부터 Vercel Functions와 전용 Neon Postgres에 영구 저장합니다. 로그인 없이 닉네임으로 참가합니다. 서버는 시작 토큰을 발급하고 종료 기록을 검증합니다. 같은 회차의 중복·동시 전송은 한 번만 반영하며, 최고 기록 갱신도 DB에서 원자적으로 처리합니다.

서버 저장이 확인된 기록에만 전체 순위를 표시합니다. 일시적 전송 실패는 대기 큐에 보관하고 연결 복구 시 재시도합니다. 브라우저 저장소가 차단돼도 서버 조회·등록은 가능하지만 재전송 대기는 열린 탭 안에서만 유지됩니다. 처음부터 서버에 연결하지 못했던 판은 등록되지 않을 수 있습니다. 예전 로컬 기록은 자동 이관하지 않고 백업으로 보존합니다. 연습과 중도 종료는 미등록입니다.

최종 보스 난이도가 바뀐 규칙은 **시즌 22**로 구분합니다. 서버의 시즌 18·19·20·21 데이터는 삭제하지 않습니다. 열린 이전 버전 탭에서 이미 시작한 판도 해당 시즌으로 저장할 수 있게 18/19/20/21/22 API를 분리합니다. 단, 이전 버전의 미전송 기록이 남은 상태에서 새로고침하여 v22로 전환한 경우 이전 대기 큐는 보존만 하고 자동 재전송하지 않습니다. 현재 게임은 명시적인 규칙 버전으로 시즌 22를 조회합니다. 시즌 20·21의 통과 시간 기록과 정렬 방식도 유지합니다. 닉네임 기반 친선 순위이며 실명 인증이나 모든 입력의 서버 리플레이 검증은 제공하지 않습니다.

## 개발 및 배포

Node.js 22와 npm을 사용합니다.

```sh
npm ci
npm start                    # http://127.0.0.1:4173
npm test                     # 전투·회피안내·사진·음향·공용순위·서버 검사
npm run balance:challenge    # 5보스 180회 입력 시뮬레이션
npm run balance:personality  # 기존 네 보스 특징 기술 검사
npm run balance:max          # 맥스 7기술·무대 장악 회피 검사
npm run balance:final        # 신규 최종 패턴의 반응 지연·구석·프레임 간격 회피 검사
npm run balance:v22          # 강화 패턴·180 전체전투·900 독립보스전
npm run build                # 화면·전투용 dist 생성
```

GitHub `main`에 push하면 `hokyung/yesulin-arcade`에 자동 배포됩니다. `/api/leaderboard`는 서버 함수이고 나머지 화면은 정적 파일입니다. Vercel 운영 환경의 `DATABASE_URL`만 서버가 사용하며 접속 문자열을 브라우저·소스·로그에 넣지 않습니다. 전용 DB `yesulin-arcade-ranking`은 Singapore 지역의 Free 요금제로 연결했고 Preview에는 운영 DB를 연결하지 않았습니다.

로컬 서버는 별도 DB 설정이 없으면 운영 순위 API에 연결합니다. 독립 개발 DB는 무시되는 `.env.local`의 `DATABASE_URL`로 설정합니다. 환경 파일·Git 폴더·서버 소스·검사 파일은 정적 파일로 노출하지 않습니다. 서버 검증용 `scope=verification`은 크루 순위와 분리됩니다.

구현 참고: [Vercel Node.js Functions](https://vercel.com/docs/functions/runtimes/node-js), [Neon 서버 드라이버](https://neon.com/docs/serverless/serverless-driver).
