# 예술in ARCADE — 최종 오디션

[게임 플레이](https://yesulin-arcade.vercel.app/) · [공개 소스 저장소](https://github.com/simhokyung/yesulin-audition-arcade)

현재 공개 사이트는 v14입니다. 아래 v15 변경은 로컬 검증 중이며 아직 공개 배포하지 않았습니다.

배우와 감독으로 네 번의 오디션에 도전하는 2D 보스 액션 게임입니다. **시간제한 없이 1차 → 2차 → 3차 → 최종 오디션**을 통과하세요.

## 플레이

1. 닉네임 2–12자를 입력하고 배우 또는 감독을 고릅니다.
2. **시작하기**는 네 오디션에 연속 도전합니다. **연습모드**는 원하는 보스 카드를 누르면 즉시 1:1 대련을 시작합니다.
3. 역할은 한 판 동안 고정되며, 다음 오디션으로 넘어갈 때 체력 65를 회복합니다.
4. 결과에서는 통과 오디션 수·점수·현재 순위를 확인하고 **재도전 / 홈**을 선택합니다. 연습 결과에는 순위가 없습니다.

**⏹ 게임 종료**는 일반 화면의 도구막대와 전체화면 하단에서 사용할 수 있습니다. 전투·컷신·음악을 먼저 멈추고 종료를 확인합니다. 계속하기 또는 Esc는 원래 정지 상태로 복원합니다. 종료를 확정하면 이번 점수를 저장하지 않고 닉네임과 역할을 유지한 채 홈으로 돌아갑니다.

| 조작 | 동작 |
|---|---|
| 방향키 | 이동 |
| Q | 누르고 있으면 3타 묶음 연속 공격; 네 번째 묶음은 강마무리 |
| W | 공격 스킬 · 재사용 4.8초 |
| E | 5초 강화 · 재사용 12초 |
| R | 충전 100% + 재사용 42초가 모두 준비되면 컷신 뒤 12연타 |
| Space | 이동 방향으로 회피; 진행 중 연타 취소 |
| Esc / P | 일시정지·재개 |

화면의 터치 버튼으로도 조작할 수 있습니다. 다른 창으로 전환하면 자동으로 일시정지합니다.

## 배우와 감독

- **배우:** Q 강마무리가 맞으면 다음 W의 마지막 화살이 큰 관통 화살로 강화됩니다. E 중 정확한 JUST 회피에 성공하면 다음 Q가 강마무리부터 시작합니다. R은 검사·궁수·액션 배우로 이어지는 12연타입니다.
- **감독:** Q가 맞으면 액션 표식을 최대 3개 쌓고 W로 연쇄 폭발시킵니다. E는 일반 피격 한 번을 막고 Q 마무리나 W에 조명·음향 후속타를 더합니다. R은 스태프 지원과 거대 슬레이트 마무리입니다.

전투 대사는 캐릭터 가까운 말풍선으로 표시합니다. 공격 회복 끝의 정확한 Q 재입력은 JUST HIT, 일반 공격 직전 회피는 JUST DODGE입니다. 콤보와 노란 스포트라이트를 활용하세요. 점수는 실제 감소한 적 체력과 JUST 보너스를 사용하며 초과 피해와 플레이 시간에는 보너스를 주지 않습니다.

## 네 번의 오디션

| 단계 | 심사위원 | 핵심 대응 |
|---|---|---|
| 1차 오디션 | 조명감독 **이그니스** | 위험 조명을 피하고 조명 리허설은 1 → 2 → 3 순서로 들어갑니다. |
| 2차 오디션 | 가면연출가 **미메** | 대역 오디션에서는 ★ 진짜만 공격하고 ○ 대역을 구분합니다. |
| 3차 오디션 | 경계심사관 **프리즘** | 조준 고정 후 옆으로 피하고, 리플레이가 따라오는 이전 경로를 벗어납니다. |
| 최종 오디션 | 종막집행관 **카덴** | 앙코르 참격의 빠른 3타 뒤 긴 예고의 4타까지 피합니다. |

각 보스는 3.0·3.2·3.4·3.8초의 등장 컷신과 고유한 **무대 장악**을 사용합니다. 등장 컷신 동안 전투는 정지합니다. 움직이는 조명, 번호 발판, 가로·세로 통로처럼 보스마다 회피법이 다릅니다. 카덴은 **칼날 파도와 추격 난무를 교대**합니다. 추격 난무는 **빠른 7연사 2묶음 → 3방향 동시 마무리**입니다. 가로 칼날은 위아래로 피하다 반전 신호에 방향을 바꾸세요. 다음 세로 칼날은 좌우로 피하고 마지막 세 공격선도 벗어나세요.

무대 장악의 실제 칼날이나 위험 범위에 닿으면 즉사합니다. Space는 빠르게 벗어나는 데 사용하며 무적으로 칼날을 통과할 수는 없습니다. 장악을 끝까지 피하면 **1.8초 반격 기회**가 열리고 보스에게 주는 피해가 20% 증가합니다. 예고 취소로는 이 기회가 열리지 않습니다.

내 체력과 상대 체력, 큰 스킬 쿨타임, 민트색 이동 안내를 먼저 확인하세요. 연습모드는 본 도전과 같은 체력·피해·공격 패턴을 사용하며 순위에 저장하지 않습니다.

## 순위

**통과 오디션 수 → 점수 → 최대 콤보 → 먼저 기록한 시각** 순입니다. 같은 닉네임은 이 기준으로 가장 좋은 기록 하나를 보여줍니다. 현재 순위는 해당 닉네임의 최고 기록 기준입니다.

순위는 **같은 브라우저 안의 친선 기록**이며 로그인이나 클라우드 동기화는 없습니다. 최근 500회 기록을 보관하고 CSV로 내보낼 수 있습니다. 시즌 15는 이전 시즌과 분리하며 이전 저장소를 삭제하지 않습니다. 연습과 중도 종료는 등록하지 않습니다.

## 개발 실행

Node.js가 필요하며 외부 패키지 설치 없이 실행할 수 있습니다.

```sh
npm start                  # http://127.0.0.1:4173
npm test                   # 엔진·연습·랭킹·음향 검사
npm run balance:challenge  # 현재 무제한 도전 시뮬레이션
npm run build              # 배포용 정적 파일 생성
```

`index.html`을 직접 여는 대신 HTTP 서버를 사용하세요. macOS에서는 `실행.command`로도 시작할 수 있습니다. 서버 종료는 터미널에서 Ctrl+C입니다.

정적 배포는 `npm run build`로 생성한 `dist/`를 사용합니다. 저장소의 `vercel.json`은 빌드 명령과 출력 디렉터리를 이 값으로 지정합니다. 현재 공개 사이트는 `dist/`를 직접 업로드해 배포하며 GitHub 커밋만으로 자동 갱신되지는 않습니다. 빌드는 게임 실행 파일과 이미지·음원만 복사하며 테스트, 연구 기록, 밸런스 보고서, 로컬 실행 도구는 배포에서 제외합니다. 소스에는 재현용 검사와 과거 연구 기록을 보관합니다.

## 리소스와 검증

HTML·CSS·ES Modules·Canvas 2D·Web Audio로 구현했습니다. 캐릭터와 컷신은 생성한 오리지널 원화, 음악·효과음은 직접 합성한 음원입니다. 원본 Flash/SWF 게임이나 애니메이션의 이미지·OST를 포함하지 않습니다. [이미지 목록](assets/asset-manifest-v9.json)에 포함 파일을 기록했습니다.

플레이 방향은 [후레쉬맨 참고 페이지](https://xn--o79am3sh5ijue0ou.kr/%ed%9b%84%eb%a0%88%ec%89%ac%eb%a7%a8/) 분석에서 출발했으며 자체 전투 엔진을 사용합니다. 결과의 작은 서비스 링크는 배우에게 [예술in 오디션 공고](https://yesulin.art/auditions), 감독에게 [제작사 서비스](https://yesulin.art/producer-service)를 안내합니다.

**자동 검사 229개와 그래픽 모형 8,977프레임 검사**를 통과했습니다. 실제 엔진을 사용한 무제한 도전 **180회 중 121회 완료**, 완료한 판의 중앙 소요 시간 136.17초를 확인했습니다. 검사 안전 상한으로 중단한 판은 없습니다. 상세 설계와 검증 범위는 [v15 기록](research-v15.md), 자동 전투 원자료는 [밸런스 보고서](challenge-balance-report.json)를 참고하세요. 자동 입력은 위험 도형의 좌표를 읽으므로 결과는 사람의 승률이 아닙니다. v15 실제 브라우저 시각 검수와 모바일 터치 전투 실기는 완료하지 않았습니다.
