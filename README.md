# 예술in ARCADE — 최종 오디션

[게임 플레이](https://yesulin-arcade.vercel.app/) · [공개 소스 저장소](https://github.com/simhokyung/yesulin-audition-arcade)

운영 사이트는 GitHub 저장소의 `main` 브랜치와 연결되어 있으며, 배포 상태는 [Vercel 프로젝트](https://vercel.com/hokyung/yesulin-arcade)에서 확인할 수 있습니다.

배우와 감독으로 네 번의 오디션에 도전하는 2D 보스 액션 게임입니다. **네 번의 관문을 넘어, 당신의 무대를 완성하세요.** 배우는 배역으로 가능성을 표현하며 합격에 도전하고, 감독은 배우·조명·음향을 지휘해 마지막 무대를 완성합니다. 시간제한 없이 1차 → 2차 → 3차 → 최종 오디션으로 진행합니다.

## 플레이

1. 닉네임 2–12자를 입력하고 배우 또는 감독을 고릅니다. 입력 예시 ‘맥스’는 안내이며 실제 닉네임으로 자동 등록되지 않습니다.
2. **시작하기**는 네 오디션에 연속 도전합니다. **연습모드**는 원하는 보스 카드를 누르면 즉시 1:1 대련을 시작합니다.
3. 역할은 한 판 동안 고정되며, 다음 오디션으로 넘어갈 때 체력 65를 회복합니다.
4. 결과에서는 통과 오디션 수·점수·현재 순위를 확인하고 **재도전 / 홈**을 선택합니다. 연습 결과에는 순위가 없습니다.

네 관문은 첫 등장·배역 발견·변화 대응·마지막 무대를 상징합니다. 전체 도전을 마친 배우에게는 **‘최종 오디션 합격!’**, 감독에게는 **‘마지막 장면, 완성!’**을 표시하며, 다음 오디션 탐색 또는 배우 모집·심사로 연결합니다. 연습 승리는 ‘연습 완료!’로 구분합니다.

**⏹ 게임 종료**는 일반 화면의 도구막대와 전체화면 하단에서 사용할 수 있습니다. 전투·컷신·음악을 먼저 멈추고 종료를 확인합니다. 계속하기 또는 Esc는 원래 정지 상태로 복원합니다. 종료를 확정하면 이번 점수를 저장하지 않고 닉네임과 역할을 유지한 채 홈으로 돌아갑니다.

| 조작 | 동작 |
|---|---|
| 방향키 | 이동 |
| Q | 누르고 있으면 3타 묶음 연속 공격; 네 번째 묶음은 강마무리 |
| W | 공격 스킬 · 재사용 4.8초 |
| E | 5초 강화 · 재사용 12초 |
| R | 충전 100% + 재사용 42초가 모두 준비되면 컷신 뒤 12연타 |
| Space | 이동 방향으로 회피; 진행 중 연타 취소 |
| Esc / P | 일시정지·재개 |

화면의 터치 버튼으로도 조작할 수 있습니다. 다른 창으로 전환하면 자동으로 일시정지합니다.

## 배우와 감독

- **배우:** Q 강마무리가 맞으면 다음 W의 마지막 화살이 큰 관통 화살로 강화됩니다. E 중 정확한 JUST 회피에 성공하면 다음 Q가 강마무리부터 시작합니다. R은 검사·궁수·액션 배우로 이어지는 12연타입니다.
- **감독:** Q가 맞으면 액션 표식을 최대 3개 쌓고 W로 연쇄 폭발시킵니다. E는 일반 피격 한 번을 막고 Q 마무리나 W에 조명·음향 후속타를 더합니다. R은 스태프 지원과 거대 슬레이트 마무리입니다.

전투 대사는 캐릭터 가까운 말풍선으로 표시합니다. 공격 회복 끝의 정확한 Q 재입력은 JUST HIT, 일반 공격 직전 회피는 JUST DODGE입니다. 콤보와 노란 스포트라이트를 활용하세요. 점수는 실제 감소한 적 체력과 JUST 보너스를 사용하며 초과 피해와 플레이 시간에는 보너스를 주지 않습니다.

## 네 번의 오디션

| 단계 | 심사위원 | 핵심 대응 |
|---|---|---|
| 1차 오디션 | 조명감독 **피노** | **팔로 스폿:** 따라오는 조명이 고정되면 옆으로 피하고 두 번째 빛도 확인합니다. |
| 2차 오디션 | 가면연출가 **대길** | **가면 동선:** FAKE에 속지 않고 번호가 붙은 실제 타격 3곳을 차례로 피합니다. |
| 3차 오디션 | 경계심사관 **이프** | **선행 프레임:** 이동 방향을 예측하는 조준이 고정되면 방향을 꺾어 실제 파편 3발을 피합니다. |
| 최종 오디션 | 종막집행관 **무빙** | **엇박자 연사:** 빠른 5발 뒤 늦은 2발까지 회피합니다. 마지막 탄 전에 멈추지 마세요. |

기존 다섯 패턴에 위 공격이 하나씩 더해져 보스마다 여섯 패턴을 사용합니다. 조준선은 따라오는 상태와 고정된 상태가 다르게 표시되며, 고정 후에는 다시 플레이어를 추적하지 않습니다. 투사체 예고선과 지나간 잔상에는 피해 판정이 없습니다. 적 투사체의 실제 몸체를 피하세요. HP·기본 피해·플레이어 QWER는 유지하고 공격 뒤 휴식만 6% 줄였습니다.

각 보스는 3.0·3.2·3.4·3.8초의 등장 컷신과 고유한 **무대 장악**을 사용합니다. 등장 컷신 동안 전투는 정지합니다. 피노의 직진/왕복 조명, 대길의 한 번/두 번 발판 교대, 이프의 교차/반전 통로처럼 보스마다 회피법이 다릅니다. 변형은 시전 횟수와 보스 페이즈로 결정되며 실제 안전 도형과 안내가 함께 바뀝니다. 무빙은 **칼날 파도와 추격 난무를 교대**합니다. 추격 난무는 **빠른 7연사 2묶음 → 3방향 동시 마무리**입니다. 가로 칼날은 위아래로 피하다 반전 신호에 방향을 바꾸세요. 다음 세로 칼날은 좌우로 피하고 마지막 세 공격선도 벗어나세요.

무대 장악의 실제 칼날이나 위험 범위에 닿으면 즉사합니다. Space는 빠르게 벗어나는 데 사용하며 무적으로 칼날을 통과할 수는 없습니다. 장악을 끝까지 피하면 **1.8초 반격 기회**가 열리고 보스에게 주는 피해가 20% 증가합니다. 예고 취소로는 이 기회가 열리지 않습니다.

내 체력과 상대 체력, 큰 스킬 쿨타임, 민트색 이동 안내를 먼저 확인하세요. 연습모드는 본 도전과 같은 체력·피해·공격 패턴을 사용하며 순위에 저장하지 않습니다.

## 순위

**통과 오디션 수 → 점수 → 최대 콤보 → 먼저 기록한 시각** 순입니다. 같은 닉네임은 이 기준으로 가장 좋은 기록 하나를 보여줍니다. 현재 순위는 해당 닉네임의 최고 기록 기준입니다.

순위는 **같은 브라우저 안의 친선 기록**이며 로그인이나 클라우드 동기화는 없습니다. 최근 500회 기록을 보관하고 CSV로 내보낼 수 있습니다. v17의 공격 패턴 변경에 맞춰 시즌 17 기록을 별도로 저장합니다. 이전 시즌 15의 기록 바이트는 보존하며 새 난이도의 순위와 섞지 않습니다. 이전 저장소를 삭제하지 않으며 연습과 중도 종료는 등록하지 않습니다.

## 개발 실행

Node.js가 필요하며 외부 패키지 설치 없이 실행할 수 있습니다.

```sh
npm start                  # http://127.0.0.1:4173
npm test                   # 엔진·연습·랭킹·음향 검사
npm run balance:challenge  # 현재 무제한 도전 시뮬레이션
npm run build              # 배포용 정적 파일 생성
```

`index.html`을 직접 여는 대신 HTTP 서버를 사용하세요. macOS에서는 `실행.command`로도 시작할 수 있습니다. 서버 종료는 터미널에서 Ctrl+C입니다.

정적 배포는 `npm run build`로 생성한 `dist/`를 사용합니다. GitHub의 `main`에 push하면 기존 Vercel 프로젝트 `hokyung/yesulin-arcade`가 자동으로 빌드하여 운영 사이트에 배포합니다. 저장소 루트의 `vercel.json`에 빌드 명령과 출력 디렉터리를 지정했으며 별도 패키지 설치는 생략합니다. 빌드는 게임 실행 파일과 이미지·음원만 복사하며 테스트, 연구 기록, 밸런스 보고서, 로컬 실행 도구는 배포에서 제외합니다. 소스에는 재현용 검사와 과거 연구 기록을 보관합니다.

## 리소스와 검증

HTML·CSS·ES Modules·Canvas 2D·Web Audio로 구현했습니다. 캐릭터와 컷신은 생성한 오리지널 원화, 음악·효과음은 직접 합성한 음원입니다. 원본 Flash/SWF 게임이나 애니메이션의 이미지·OST를 포함하지 않습니다. [이미지 목록](assets/asset-manifest-v9.json)에 포함 파일을 기록했습니다.

헤더·결과에는 [예술in 공식 사이트](https://yesulin.art/)의 로고 원본을 사용합니다. 투명 배경과 비율을 유지하고, CSS 색상 필터로 글자를 밝게 바꾸면서 청록·보라 계열의 심볼 색을 살렸습니다. 별도 바탕이나 테두리 없이 게임 배경에 바로 배치합니다. 출처와 파일 해시는 [로고 기록](assets/asset-manifest-v16.json)에 보관합니다.

플레이 방향은 [후레쉬맨 참고 페이지](https://xn--o79am3sh5ijue0ou.kr/%ed%9b%84%eb%a0%88%ec%89%ac%eb%a7%a8/) 분석에서 출발했으며 자체 전투 엔진을 사용합니다. 결과의 작은 서비스 링크는 배우에게 [예술in 오디션 공고](https://yesulin.art/auditions), 감독에게 [제작사 서비스](https://yesulin.art/producer-service)를 안내합니다.

현재 전투의 검사 범위와 제한은 [v17 검증 기록](research-v17.md), 수치 결과는 [최신 밸런스 보고서](challenge-balance-report.json)에 기록합니다. 실제 게임 엔진에 입력을 전달하는 자동 시뮬레이션이며 사람의 승률을 나타내지 않습니다. 브라우저 화면 실기와 모바일 터치 전투는 별도의 확인이 필요합니다.
